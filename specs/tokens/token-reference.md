# Master Token Reference

Complete list of Layer 2 semantic usage tokens from `tokens.css`.

| Token Name | Category | Purpose | Example Value |
|---|---|---|---|
| `--color-primary` | Color | Main brand color for action taking | `#646cff` |
| `--color-primary-hover` | Color | Hover state for primary | `#535bf2` |
| `--color-success` | Color | Success semantic states | `#28a745` |
| `--color-warning` | Color | Warning semantic states | `#ffc107` |
| `--color-error` / `--color-danger` | Color | Error, destruction semantic states | `#ff4646` |
| `--color-info` | Color | Informative semantic states | `#17a2b8` |
| `--color-bg-primary` | Color | Base page background | `#ffffff` |
| `--color-bg-secondary` | Color | Subtle offset background | `#f9f9f9` |
| `--color-bg-tertiary` | Color | Contrasting component background | `#f0f0f0` |
| `--color-bg-overlay` | Color | Translucent modal backing | `rgba(0, 0, 0, 0.5)` |
| `--color-text-primary` | Color | Primary text color | `#242424` |
| `--color-text-secondary` | Color | Muted, descriptive text | `#666666` |
| `--color-text-tertiary` | Color | Highly muted text, placeholders | `#999999` |
| `--color-text-inverse` | Color | Text over dark backgrounds (white) | `#ffffff` |
| `--color-border` | Color | Default border color | `#cccccc` |
| `--color-border-hover` | Color | Hovered state for borders | `#444444` |
| `--space-xs` | Spacing | ~4px inner spacing | `0.25rem` |
| `--space-sm` | Spacing | ~8px component spacing | `0.5rem` |
| `--space-md` | Spacing | ~16px layout gaps | `1rem` |
| `--space-lg` | Spacing | ~24px structural gaps | `1.5rem` |
| `--space-xl` | Spacing | ~32px outer padding | `2rem` |
| `--space-xxl` | Spacing | ~48px section padding | `3rem` |
| `--radius-subtle` | Borders | Very mild rounding (4px) | `var(--radius-1)` |
| `--radius-rounded` | Borders | Standard card/modal rounding (8px) | `var(--radius-2)` |
| `--radius-round` | Borders | Complete pill shape (9999px) | `var(--radius-3)` |
| `--radius-circle` | Borders | Mathematical circle (50%) | `var(--radius-full)` |
| `--text-[size]` | Typography | Pre-computed scales xs to 4xl | `1rem` |
| `--font-[weight]` | Typography | Text density normal to bold | `400` |
| `--leading-[var]` | Typography | Line heights | `1.5` |
| `--shadow-[var]` | Elevation | Drop shadows sm through xl | *computed* |
| `--z-[var]` | Elevation | Semantic structural z-indices | `30` |
| `--transition-[var]` | Motion | Animated transitions fast to slow | `150ms ease` |
